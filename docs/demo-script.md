# Demo video script (under 3 minutes)

Record after the UI redesign lands, against a deployment with a real `NEBIUS_API_KEY`. Start from an empty database so onboarding is live; keep the seeded demo as a backup.

| Time | Screen | What to show | Voice-over |
|---|---|---|---|
| 0:00–0:15 | Home | Title and the one-line idea | "TOMORA connects who you are today with who you want to become, and turns that into real steps." |
| 0:15–0:40 | Onboarding | Fill dream, situation, challenges, values, coaching style | "I tell it my 10-year dream, what I have, and what's in the way. This becomes the first notes in a Markdown vault I own." |
| 0:40–1:05 | Future | Generate the letter; scroll it | "Nemotron on Nebius writes a letter from one possible future me. It's an imagined direction, not a prediction, and it's labelled that way." |
| 1:05–1:45 | Chat | Ask "Help me plan my first step"; reply streams; point at "remembered …" tags and "1 proposal waiting" | "The future-self agent runs in Docker Agent. Before answering it searches my vault through an MCP tool, and it proposes a plan instead of acting on its own." |
| 1:45–2:10 | Plan | Approve; tasks appear; mark one done | "Nothing is created until I approve. Approved plans become goals, tasks and linked notes." |
| 2:10–2:35 | Daily | Print today's issue | "TOMORA Daily is a newspaper about my journey. Every item links to something I actually did." |
| 2:35–2:55 | Obsidian | Open the vault folder in Obsidian; show the graph | "All of it is plain Markdown with wiki-links, so my memory stays readable and portable." |
| 2:55–3:00 | Close | Repo URL, "Built with NVIDIA Nemotron, Nebius Token Factory and Docker Agent" | "Meet the person you're becoming." |

Recording tips: 1440×900 browser window, dark theme, hide the bookmarks bar, pre-type long onboarding answers, and do one dry run so model latency is known.
